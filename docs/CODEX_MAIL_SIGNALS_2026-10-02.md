## 남은 쟁점·미실측

- 오늘 Trajectory의 표/문장이 섞인 원문 줄은 추출하지 않는다. 한국어 요약에85.42%가 있어도 이를 독립적인 비교 셀로 만들지 않았다. 해당 논문의 HTML 수신 결과와 표 미추출의 상세 원인은 오늘 로그에 보존되지 않아 확인 불가이다. 벤치마크/기법 식별과 복합 표의 구조 복원은 별도 보강 대상이다.
- 성능 관측 DB의 비교 키는 benchmark/metric이며 전체 조건을 저장하는 구조가 아니다. 외부 조사에는 일부 양쪽 원문 조건 대조가 있지만 backbone·추론 조건까지 모두 확인되는 계약은 아직 아니다. 새 카드의 논문 간 구역은 값·출처·차이와 확인 한계를 보이고 우열을 판정하지 않는다. 기존 research_frontier의 상태 API/외부 조사 계약 전체를 이번 표시 변경으로 완성했다고 말하지 않는다. 기존 관측 best API는 원 float 값/모델/논문만 주고 원 셀의 단위·척도를 주지 않으므로, 그 값으로 단위를 복원하거나 차이를 계산하지 않는다.
- 문장 근거는 저자의 자기 보고이며 독립 실험 재현 결과가 아니다. 원문 인용과 S번호가 읽는 사람에게 그 경계를 보여준다. 성능 값·표 조건을 LLM으로 채우지 않았다.
- 기존 선택적 과거 흐름(history)은 유지했다. 오늘 원래 메일에는 새 과거 연결을 만들어 넣지 않았다. 새 실제 모델 출력의 의미 정확성/다음 근무일 발송/실제 Gmail·Outlook·Naver 클라이언트 배치는 미실측이다.
- SMTP 성공은 수신 서버 수락이며 사용자의 수신함 열람까지 확인한 것은 아니다. 새 관측 박스는 앞으로 생성되는 메일에 반영되고, 오늘 동일 내용 재발송에는 본문을 새로 추가하지 않는다.
