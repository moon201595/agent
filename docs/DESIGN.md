# DESIGN.md — 운영 화면(review_app) 디자인 기준

2026-09-16. 화면을 고칠 때마다 CSS 조각을 그때그때 넣다 보니 색(cyan 잔재 `#0284C7`·`#4C6EF5` vs 테마 `#3B5BDB`)과 크기가 어긋났다.
이 파일이 기준이다 — 새 요소는 여기 토큰·규칙으로만 만든다. 형식은 getdesign.md/refero 의 DESIGN.md 관행(토큰 + 의도 + 금지)을 따른다.
Streamlit 이라 적용 수단은 `.streamlit/config.toml`(테마)과 `review_app._inject_custom_style`(CSS) 둘뿐이다. HTML 프론트로 옮겨도 이 파일은 그대로 쓴다.

## 1. 성격
"차분한 운영판". 매일 아침 한 사람(나중엔 팀)이 몇 분 보는 화면 — 눈에 띄는 것보다 **읽히는 것**이 우선. 색은 파랑 한 계열, 나머지는 회색.
장식이 아니라 상태·수치·이력이 주인공이다. 브랜드 느낌을 내려고 애쓰지 않는다.

## 2. 색 토큰
| 토큰 | 값 | 쓰는 곳 |
|---|---|---|
| `--blue` | `#3B5BDB` | 주 동작 버튼, 선택 표시, 링크, 그래프 첫 색 |
| `--blue-dark` | `#2F4AB8` | hover, 연한 배경 위 글자 |
| `--blue-100` | `#EEF2FF` | 선택된 항목 배경, 칩 배경 |
| `--blue-200` | `#D6DEFA` | 선택 테두리, 구분선(강조) |
| `--ink` | `#111827` | 제목·본문 |
| `--ink-2` | `#374151` | 본문 보조 |
| `--muted` | `#5B6577` | 캡션·라벨 (흰 배경 대비 4.5:1 이상) |
| `--line` | `#E5E7EB` | 카드·표·입력 테두리 |
| `--surface` | `#FFFFFF` | 본문·카드 |
| `--canvas` | `#F6F8FB` | 사이드바 |
| 상태 `done` | `#1E9E5A` | 완료 (원 + 글자) |
| 상태 `partial` | `#E08A2E` | 일부 |
| 상태 `failed` | `#D0433B` | 실패 |
| 범주 팔레트 | `#3B5BDB #E8590C #2F9E44 #9C36B5 #0CA678 #E64980 #F08C00 #1098AD #845EF7 #5C940D` | 선 그래프(키워드별) — 순서 고정, 순환 금지 |
| 순차 팔레트 | `#86B6EF → #104281` | 크기(가중치) 한 색상 단계 |

상태색은 상태에만 쓴다(계열 4번째 색으로 쓰지 않는다). 파랑을 두 톤 이상 섞지 않는다(cyan·sky 금지).

## 3. 타이포
Pretendard Variable(jsdelivr), 대체 `-apple-system, "Segoe UI", sans-serif`. 아이콘 폰트 요소(`stIconMaterial`)는 제외.

| 역할 | 크기 | 굵기 | 비고 |
|---|---|---|---|
| 앱 제목(사이드바 브랜드) | 1.15rem | 700 | 부제는 0.85rem·muted |
| 페이지 제목(h3, `st.subheader`) | 1.35rem | 700 | 자간 -0.015em |
| 구역 제목(h2, 프로필 이름) | 1.2rem | 700 | id 칩은 0.75rem |
| 소제목(h3 안 `**…**`) | 0.95rem | 600 | |
| 본문 | 0.95rem(≈14.5px) | 400 | 줄 간격 1.55 |
| 캡션·라벨 | 0.8rem | 400 | muted |
| 지표 숫자(`st.metric`) | 1.55rem | 600 | `tabular-nums`, 자간 -0.01em |
| 지표 라벨 | 0.78rem | 500 | muted |

숫자는 항상 `font-variant-numeric: tabular-nums`(표·지표·그래프 축). 제목에 문장부호·이모지 없음.

## 4. 간격·모양
- 4px 배수. 카드 안쪽 여백 16~20px, 카드 사이 12px, 구역 사이 24~32px.
- 모서리: 입력·버튼 8px, 카드·확장 패널 12px, 칩 6px.
- 그림자: 한 단계만 `0 1px 2px rgba(16,24,40,.06)`. hover 에서 `0 2px 6px rgba(16,24,40,.08)`. 색 있는 그림자 금지.
- 테두리는 `--line` 1px. 선택은 배경(`--blue-100`) + 테두리(`--blue-200`)로, 채운 파란 덩어리로 표시하지 않는다.
- 본문 최대 폭 제한 없음(넓은 모니터에서 오른쪽 비지 않게), 좌우 여백 2rem.

## 5. 구성 요소 규칙
- **사이드바 내비**: 항목 셋(운영 현황·논문 DB·시스템). 비선택은 배경·테두리 없는 텍스트+아이콘, hover 는 `--canvas` 보다 한 단계 진한 배경, 선택은 `--blue-100` 배경 + `--blue-dark` 글자·아이콘. 아이콘은 단선(1.6px) 파랑 `#3B5BDB`.
- **프로필 카드**: 흰 카드, `--line` 테두리, 선택된 카드는 `--blue-200` 테두리 + 위쪽 3px 파란 선. 카드 안 "보기" 버튼은 비선택만 보이고 선택은 라벨 "보는 중"으로 비활성.
- **지표 줄**(`st.metric` ×4): 타일로 감싸지 않는다 — 크기를 줄이고 라벨을 위에, 캡션을 아래에. 숫자 뒤 단위(통·건·편)는 숫자와 같은 크기.
- **상태**: 색 원(●) + 글자. X·체크 문자 금지.
- **표**: 밀도 높게(행 높이 32px), 헤더 muted 0.8rem, 숫자 오른쪽 정렬·tabular.
- **그래프**: 축·격자는 `--line`/`--muted`, 제목 없음(위 소제목이 제목), 범례는 아래, 선 끝 직접 라벨. 팔레트는 §2.
- **버튼**: 화면당 primary 하나(저장·적용). 나머지는 secondary(흰 배경·`--line`). 위험 동작(되돌리기)은 secondary + 확인 단계.
- **칩**(`[S번호]`, revision, id): `--blue-100` 배경·`--blue-dark` 글자·0.8em.
- **알림**: Streamlit 기본 의미색 유지, 모서리 8px.

## 6. 금지 (Hallmark 의 "AI 티" 검사에서 앱에 해당하는 것)
이모지 아이콘 · 그라데이션 배경/글자 · 색 있는 그림자 · 3가지 이상의 강조색 · 큰 숫자 하나를 영웅처럼 띄우는 지표 타일 · 장식용 아이콘 ·
"✨AI" 같은 라벨 · 가짜/자리표시 수치 · 카드 안에 카드 · 제목마다 다른 크기 · 정렬 안 맞는 열 폭 · `Made with Streamlit`·Deploy 메뉴 노출.

## 7. 적용 위치
- 테마: `.streamlit/config.toml` (`primaryColor=#3B5BDB`, `secondaryBackgroundColor=#EEF2FF`, `textColor=#111827`)
- CSS: `review_app._inject_custom_style` — 토큰은 `:root` 변수로 한 번만 선언하고 나머지는 변수만 쓴다.
- 그래프: `review_app._LINE_PALETTE`(§2 범주), `_WEIGHT_RAMP` 계열(순차), `_STATUS_COLORS`(상태).
