## 2. 파이프라인 ①~⑨와 현재 상태

05:00 KST cron → `run_daily_scan.sh` → `run_profile_scan.py --all --send`가 무인 운행한다(README; run_daily_scan.sh:47). 자동 흐름은 ①→②→③→④→⑤→⑧→⑨다. ⑥은 사이드 UI이며 승인 게이트가 아니다.

| 단계 | 담당·상태 |
|---|---|
| ① 검색 | delta_search·s2_delta: core_topics OR + S2 씨앗, 델타 커서·429 백오프(README) |
| ② 선별 | profile_scoring.rank_key: (계층, −날짜, −적중폭, −도메인, 키). 가중합 대신 튜플 정렬(P §8-86; profile_scoring.py:233) |
| ③ 확보 | server: arXiv·OA·PDF, 실패 시 초록/서지 구분(README) |
| ④ 요약 | summarize_engine·batch_summarize: Gemini→Groq 무료 API(README) |
| ⑤ 검증 | verify·sentence_grounding: 인용 문장 수치 대조(P §5) |
| ⑥ 판단 | review_app·review_core: 열람·수동 재처리(README) |
| ⑦ 재현 | code_finder·docker_runner: ④⑤ 저장 뒤 launch_background로 백그라운드 자동 전이(batch_summarize.py:247·259, review_core.py:257). 메일 경로는 결과 대기(run_profile_scan.py:748) |
| ⑧ 축적 | storage·research_profile: SQLite 저장·관측 보존(P §8-87) |
| ⑨ 배달 | trend_report·digest·email_delivery: 동향 근거 ID [P번호:A/R/S], HTML·Gmail SMTP, 제목 “[연구 동향 브리핑] 날짜”(P §8-80; run_profile_scan.py:986) |
