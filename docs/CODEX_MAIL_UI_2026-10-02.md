## 7. 재지적 — 실제 표 칸 안의 항목명 중앙 정렬

사용자가 요구한 것은 표의 왼쪽 셀 안에서 항목명을 가로·세로 중앙에 맞추는 것이었다. 앞 구현은 중첩 inline-table과760px CSS에 의존하여 스타일 태그가 제거되면 항목명이 본문 위로 쌓였다. 그 상태를 “표 칸의 중앙 정렬 완료”로 설명한 것은 요구를 충족하지 못한 판단이었다. 실제 수신앱의 스타일 제거를 실측한 것은 아니며, 이 폴백 동작은 코드와 앞 브라우저 측정으로 확인했다.

실제 한 table의 각 tr에 왼쪽 항목명 td와 오른쪽 설명 td를 둔다. 왼쪽 td 자체에 align=center/valign=middle와 인라인 중앙 정렬을 지정하고,오른쪽은 align=left/valign=top이다. 모바일도 실제 두 칸을 유지하며 항목명 폭/안쪽 여백만 줄인다. 원래 문장·수치·근거·토글·반응·회색폭/흰카드 구분은 보존한다. 새 회귀는 중첩 표를 실제 한 표로 인정하지 않는다. 수정 전 실패·수정 후·변이·실측·적용·메일 결과는 아래에 추가한다.
