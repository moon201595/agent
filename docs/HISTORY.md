## 바뀌지 않은 것

- **무료 API 와 구독 CLI 만.** 유료 티어·결제는 해법으로 쓰지 않았다(Cerebras 는 결제 요구로 8/28 폐기).
- **LLM 은 제안·서술, Python 은 판정·적용.** 수치 대조·순위·변경 적용은 결정적 코드다.
- **보조 단계가 실패해도 아침 메일은 나간다**(검색이 전부 죽은 날만 예외 — 0편 메일이 거짓말이 된다). 실패는 실패로 적는다 — 성공으로 기록된 재현 실패(TSPulse)가 이 원칙의 계기였다.
- **외부 논문·링크·저장소는 비신뢰 입력.** 재현은 네트워크 없는 컨테이너에서, 메일 링크는 허용 목록과 감사를 거친다.
