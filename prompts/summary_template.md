# 논문 정리 템플릿 (하네스 프롬프트 자산 v1)

이 파일은 하네스의 프롬프트 자산이다. 수정하면 반드시 커밋 이력을 남기고,
`eval.py`로 회귀 여부를 확인한 뒤 반영한다.

## 작성 규칙

- 문체는 평서체("~했다/~이다")로 통일한다. 개조식("~함/~임") 금지.
- 논문·수치는 원문에서 확인한 것만 쓴다. 미확인 수치 인용 금지.
- KPI·계획 수치는 반드시 "(목표)"를 붙여 달성치와 구분한다.
- 출처를 댈 수 없는 인용구·통계는 쓰지 않고, 불확실하면 불확실하다고 쓴다.
- 모든 섹션을 빠짐없이 다룬다. 간단히 다루더라도 생략하지 않는다.

## 작업 순서 (paper_harness_mcp 도구 사용)

1. `fetch_paper`로 원문을 저장한다.
2. `get_paper_text`로 원문을 나눠 읽으며 아래 템플릿을 채운다.
3. `save_summary`로 저장한다 — 수치 검증이 자동 수행된다.
4. 검증 보고서의 unmatched 항목을 하나씩 처리한다:
   - 원문에 실제로 없는 숫자 → 요약에서 삭제하거나 근거를 교체한다.
   - 원문 외 출처(예: 과제 KPI)의 숫자 → 요약문에 출처를 명시했는지 확인한다.
   - PDF 추출 누락 의심 → 원문 PDF에서 직접 확인 후 그대로 둔다.
